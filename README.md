# Nokia5110_Display
Bağlantı Şeması
Aşağıdaki şemaya göre bağlantıları dikkatlice yapınız. Dirençlerin bağlantı yönü yoktur.

Nokia 5110 Pin	Bağlantı (Direnç Üzerinden)	Arduino Uno Pin
RST (Reset)	1kΩ Direnç	Dijital Pin 3
CE (CS)	1kΩ Direnç	Dijital Pin 4
DC (D/C)	1kΩ Direnç	Dijital Pin 5
DIN (MOSI)	1kΩ Direnç	Dijital Pin 6
CLK (SCLK)	1kΩ Direnç	Dijital Pin 7
VCC	Doğrudan	3.3V
BL (Backlight)	220Ω Direnç	5V
GND	Doğrudan	GND
